## 军师能做什么

<CardGrid stagger>
  <Card title="终局播报" icon="star">
    一局打完，先发一张马匹排行的文字卡片，再用语音播报，还会点出一两个关键时刻。
    [看终局播报](/features/game-end/)
  </Card>
  <Card title="军师赛前锦囊" icon="rocket">
    游戏还在载入界面，军师就根据队友的马厩战绩给出锦囊，打完还会回顾这一卦准不准。
    [看赛前锦囊](/features/pregame/)
  </Card>
  <Card title="车队内战" icon="random">
    同队开黑的朋友不止一位时，单独给你们几位排个名，选出车队 MVP 和本局背锅。
    [看车队内战](/features/party/)
  </Card>
  <Card title="马厩" icon="open-book">
    每一局的结果都会记进马厩，用 `/stable` 看特等马率、没有马次数、强弱项和近况。
    [看马厩](/features/stable/)
  </Card>
  <Card title="/why 判决书" icon="document">
    不服这局的判定？`/why` 会画出雷达图，讲清楚哪里拖了后腿，你也可以上诉。
    [看判决书](/features/why/)
  </Card>
  <Card title="马报" icon="pencil">
    每天和每周自动发一份榜单，谁是特等马，谁是没有马，一目了然。
    [看马报](/features/ma-bao/)
  </Card>
</CardGrid>

## 先说清楚三件事

- 目前只有中文输出。
- 目前只支持北美服（NA）的账号。
- 机器人跑在管理员自己的电脑上，那台电脑开着、机器人在运行的时候，军师才在岗。
