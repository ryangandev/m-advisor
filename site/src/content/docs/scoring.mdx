军师怎么决定谁是特等马、谁是没有马？
一句话：**按位置的要求打分，和同位置的玩家比，然后在你自己这一队里排名。**

## 为什么不用 KDA

KDA 衡量的是你怎么换人头，而不是你的位置要你干什么。
在军师的参考样本里，如果只看 (击杀 + 助攻) / 死亡 来排队友，上单有 35% 的概率是全队最后一名，而辅助和打野只有 10% 和 13%，因为助攻把他们的数字撑高了。
一个为了保护 C 位而倒下的辅助，和一个孤身守线、人头不多的上单，在 KDA 里一个看不出贡献，一个天天被冤枉。

军师的目标是让每个位置都有差不多的机会拿特等马，也有差不多的机会拿没有马。

## 第一步：和同位置的玩家比

军师手里有一份参考样本：从北美服白银到钻石的单双排对局中收集的几百局真实数据，每个位置都有近千名玩家。
你这一局的每项数据，都会放进这份样本里，和**同一个位置**的玩家比较，得到一个百分位。

所以比的是上单和上单，辅助和辅助，不会拿辅助的伤害去和射手比。
位置不明的玩家，用不分位置的整体样本来比。

## 第二步：九个维度

军师把表现拆成九个维度，每个维度由几项数据合成，数据都按每分钟或占队伍总量的比例处理，所以长局和短局可以公平比较：

| 维度 | 看什么 |
| --- | --- |
| 输出 | 伤害占队伍的比例，每分钟伤害 |
| 参团 | 参与击杀的比例，每分钟的击杀加助攻 |
| 生存 | 每分钟死亡（越少越好），以及击杀助攻和死亡的比 |
| 经济 | 每分钟金币、补刀和经验 |
| 前排 | 承受伤害占队伍的比例，自身减免的伤害 |
| 视野 | 视野得分、控制守卫、排掉的眼 |
| 资源 | 大龙、小龙等史诗野怪，防御塔和建筑伤害 |
| 功能 | 治疗和护盾、控制时间、控制次数 |
| 对线 | 和对位对手的金币差、经验差、补刀领先 |

## 第三步：位置决定哪些维度更重要

每个位置对这九个维度的看重程度不一样。
大致是这样：

- **射手和中单**：输出占的比重最大。
- **上单**：输出和前排最重。
- **打野**：资源最重，其次是参团和输出。
- **辅助**：视野、功能和参团最重，输出和经济占的比重很小。

某个维度对你的位置不重要，它就几乎不影响你的分数，比如射手不用承受伤害，辅助不会因为经济低被惩罚。
这一局缺失的数据会被跳过，其余维度的比重自动补上。

## 得分

九个维度按位置的比重合成一个总分，再和同位置的玩家校准一次。
最后的得分在 0 到 10 之间，意思很直观：**8.5 分就是比 85% 的同位置玩家强。**

这个校准让辅助和 C 位拿特等马的机会一样大。
比赛输赢不是输入，赢的一队得分更高，只是因为他们的数据确实更好。

## 第四步：只在你自己的队内排名

军师把同队五个人的得分从高到低排：

1. 特等马
2. 上等马
3. 中等马
4. 下等马
5. 没有马

得分相同时，会依次比总分和账号标识来分先后，保证结果每次都一样。

所以档位是队内的相对名次。
你可以打得很好却是下等马，因为队友打得更好；也可以打得一般却是上等马。
想知道某一局到底差在哪，用 [/why 判决书](/features/why/) 看每一项。

## 它够公平吗

军师在参考样本上测试过：每个位置拿到每一档的比例都在 16% 到 23% 之间，理想值是 20%。
也就是说，不会有哪个位置天生更容易当没有马。
赢的一队的特等马，在 89% 的对局里得分高于输的一队的特等马。

## 不评分的对局

重开局、被系统中止的对局和不到 10 分钟的对局不排名，军师会说一声「不予鉴定」。

## 军师的点评

表扬和批评都要有依据：

- 夸特等马，会引用他最强的那个维度里的一项数据，并且这项数据本身要够亮眼；
- 损没有马，会引用他最弱的那个维度里的一项数据，并且这项数据本身确实难看；
- 如果没有哪项数据够格，就用一句泛泛的夸奖或调侃；
- 对局有时间线时，可以用一个具体的瞬间替换那句数据，见 [终局播报](/features/game-end/#关键时刻)。

军师的话只评论游戏里的操作，不涉及身份、外貌或家人。
同一局的措辞永远一样。

<Aside type="caution" title="还在调的地方">
关键时刻里各项的判定阈值（比如多大的赏金算数、多近算同一波团战）目前是初步估计，还没有用大量真实的时间线样本校准。
评分用的参考样本采集于 2026 年 10 月初，对应游戏的 16.15 到 16.19 版本，版本变化之后可以重新采集。
</Aside>
