终局播报是军师的主业：你们打完一局，军师把同队五个人排成特等马到没有马，先发文字，再开口念。

## 马匹排行

军师只评说话这一方的五个人，包括没被绑定的路人队友。
五个人按本局表现从高到低排成五档，每个人正好占一档：

| 名次 | 马匹 |
| --- | --- |
| 第 1 | 👑 特等马 |
| 第 2 | 🐎 上等马 |
| 第 3 | 🐴 中等马 |
| 第 4 | 🫏 下等马 |
| 第 5 | 🪦 没有马 |

所以这里的档位是队内的相对名次，而不是绝对水平的评级。
一队里总有一个特等马，也总有一个没有马，哪怕大家都打得不错。
排名怎么算的，见 [评分规则](/scoring/)。

对面五个人不评分，也不会被点名。

## 文字战报

对局结束后，军师先在语音频道的文字聊天里发一张战报卡片，标题是「策马军师 · 本局马匹鉴定」。
卡片上有：

- 本局胜负和时长的一句话总结；
- 马匹排行：每个人的档位、英雄、召唤师名、得分（满分 10 分）和 KDA，这份战报替谁说话，谁的名字后面就带 (召唤者) 标记；
- 军师表扬：夸特等马；
- 军师批评：损没有马；
- 如果赛前给过锦囊，还有一栏 [锦囊回顾](/features/pregame/#锦囊回顾)；
- 同队有两位以上被绑定的朋友时，紧跟着的另一张 [车队内战](/features/party/) 卡片。

卡片会 @ 打了这一局、还在这个语音频道里的被绑定成员，其他人不会被 @。
战报里的召唤师名不会触发任何 @，包括 @everyone。

文字总是先发，语音随后开始生成和播放，所以即使语音要等一会儿，你也能马上看到结果。

## 语音播报

文字发出之后，军师加入语音频道，用中文念出一份战报：

1. 先说这一局赢了还是输了，打了多少分钟。
2. 再把五位的档位、英雄、名字和得分依次念一遍。
3. 夸一句特等马，损一句没有马。
4. 同队有两位以上被绑定的朋友时，最后加一句车队内战。

一份五匹马的战报，语音大约一分钟，通常在 60 到 80 秒之间。
军师会等前两句语音准备好才进频道，所以不会进来先沉默半天。
播完之后军师自己离开频道。

如果几局的战报排在一起，同一个服务器里一次只播一份，后面的排队等前面的播完。

### 语音风格

用 `/announcer style` 选择军师的声音：

| 选项 | 声音 |
| --- | --- |
| Sweet Girl | 甜美女声（Serena） |
| Old Man | 大叔声（Uncle_Fu），默认 |

这个选项对整个服务器生效，任何成员都可以改。

## 关键时刻

如果 Riot 提供了这一局的时间线，军师有时会把夸奖或批评里的数据换成一个具体的瞬间。
例如：

- 夸特等马：一波三杀、全身而退地打赢一场团战、拿下带高额赏金的人头、拿一血。
- 损没有马：团战里第一个倒下、小龙前先倒下、被对面拿走高额赏金、被拿一血。

这些话会带上游戏时间，说的都是在时间线上真实发生过的事。
每次最多引用一个关键时刻给特等马、一个给没有马，换掉的是原来那一句数据，战报不会因此变长。

时间线是可有可无的调味。
如果时间线拿不到、或者等了几秒还没回来，军师就照常用统计数据点评，不会因此卡住战报。
没有合适的瞬间时，同样回到数据。

提到对面的人时，只会说「对面打野」「对面中单」这样的位置，不会出现对面的名字或英雄。

## 段位变化

单双排和灵活组排打完之后，战报的马匹卡片会多一栏「段位变化」。
同队每位被绑定的成员各占一行，不管他在不在语音频道里。
路人队友和对面的人没有这一行，对面的朋友也没有。

一行写的是这位成员现在的段位和 LP，后面跟这一局的变化：

| 情况 | 这一行写什么 |
| --- | --- |
| 同一个段位里涨跌 | 单双排 黄金 II · 86 LP · 本局 +22 |
| 升段 | 单双排 铂金 IV · 7 LP · 本局 +24 · 晋级！ |
| 掉段 | 单双排 白银 I · 75 LP · 本局掉段 |
| 两次查询之间隔了好几局 | 只写当前段位和 LP，说明本局变化算不出来 |
| 定级赛打完 | 单双排 · 定级完成：黄金 IV |
| Riot 的段位数据还没更新 | 单双排 · 段位还没更新，稍后补上 |

掉段那一行只写新的段位和 LP，不写变化的数字，因为掉段时实际扣了多少 LP，军师算不准。

如果 Riot 更新得慢，战报会先发出去，那一行写「段位还没更新，稍后补上」。
军师之后会再查几次，查到了就把这条战报编辑一次，补上段位；这条消息的其他内容不变。
要是 Riot 始终没有更新，那一行会改成「段位一直没更新，本局变化算不出来」。
这条战报的发出不会因为段位而变慢：军师最多和时间线一起多等几秒。

语音战报不念 LP，所以它的长短和有没有段位数据无关。
没有段位的账号不会显示这一行。
段位查询失败时，这一行会写「段位暂时查不到」，不会影响战报。
如果 Riot 对段位查询返回 401 或 403，这个功能会关掉，这一行也不再显示。

## 段位播报

成员每一次大段位或小段位的变化，升段或掉段，都会再单独发一张「段位播报」文字卡片。
黄金 I 升到铂金 IV，或者黄金 IV 掉到白银 I 之类，都算。
大师、宗师、王者之间的变动靠的是分数线，不算升降，所以不播报。

- 卡片紧跟在战报文字后面，每人一行，例如「单双排 晋级：黄金 I → 铂金 IV · 7 LP」。
- 同一位成员在同一局里只播报一次；如果他的变化要等 Riot 更新才看得出来，会补发一张新卡片，已经播报过的人不会重复。
- 卡片后面还有一句简短的语音，排在这一局的语音战报之后，不会抢在前面。
  军师念的是「军师贺喜」这一类的短话，每人一句，最多念前两位，不会拖长。
  同一局有第三位或更多成员升降段时，后面的人只出现在文字卡片里。
- 要是这支队伍里已经没有人在语音频道里，就只有文字卡片，没有语音。
- 模拟模式下，卡片标题是「模拟数据 · 段位播报」，语音以「模拟段位播报」开头。

## 军师不评的对局

下面几种对局，军师会说一声「不予鉴定」，不排名也不记录：

- 重开局（remake）；
- 被系统中止、没有分出胜负的对局；
- 不到 10 分钟的对局。

## 播报的前提和时机

- 被绑定的成员要在语音频道里，机器人要有那个频道的权限。
- 队列是 [快速开始](/quick-start/) 里列的那几种，并且是北美服账号。
- 军师大约每 45 秒查一次有没有新的对局，Riot 的对局数据也要在比赛结束后过一会儿才能查到，再加上语音生成的时间，所以不是秒播。
- 播不出来的常见原因见 [常见问题](/faq/)。

<Aside type="note">
军师说话只评论游戏里的操作，不涉及一个人的身份、外貌或家人。
同一局永远生成同样的话：措辞由对局编号决定，重新播也一样。
</Aside>
