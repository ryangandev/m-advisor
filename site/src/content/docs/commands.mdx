下面按谁能用来分组，每个命令都写了选项和回复是公开还是私下。

每个命令的用途和选项，见下面各自的小节。

<Aside type="note" title="管理员命令的权限">
`/report-settings`、`/stable-erase`、`/testvoice` 和 `/simulate` 对非管理员默认是隐藏的。
`/bind`、`/unbind`、`/bindings` 在命令列表里大家都看得到，但非管理员运行时会被拒绝。
`/announcer` 的 `pregame_voice` 选项同理，非管理员填了会被拒绝。
`/testvoice` 和 `/simulate` 只用于测试，只能在配置了测试服务器的那个服务器里用。
</Aside>

## 所有人可用

### /profile

查一个英雄联盟玩家的战绩概览，不需要被绑定。

| 选项 | 必填 | 说明 |
| --- | --- | --- |
| `riotid` | 是 | Riot ID，格式 `召唤师名#标签` |

回复里有等级，以及单双排和灵活组排的段位、胜点和胜率。
目前只能查北美服账号。

### /recent

看被绑定成员当前的语音和监听状态，以及他们账号最近的对局。

| 选项 | 必填 | 说明 |
| --- | --- | --- |
| `count` | 否 | 每个账号显示几局，1 到 10，默认 5 |
| `user` | 否 | 只看这一位成员，默认看整个服务器 |

回复只有你自己看得到。
最近的对局包含所有队列，不限于军师会播报的那几种，并且会标出哪一局是起点、哪一局已经播过。

### /stable

看一位被绑定成员的 [马厩](/features/stable/) 档案。

| 选项 | 必填 | 说明 |
| --- | --- | --- |
| `user` | 否 | 要看的成员，默认是你自己 |

回复是公开的。

### /why

看一局的 [判决书](/features/why/)，卡片和雷达图下面有上诉按钮。

| 选项 | 必填 | 说明 |
| --- | --- | --- |
| `user` | 否 | 要看的成员，默认是你自己 |
| `match` | 否 | 要看的对局，默认最近一局，输入时自动补全最近 25 局 |

找到记录时回复是公开的，找不到时只有你自己看得到原因。
上诉按钮只有这份判决书所属的成员能按。

### /report

看 [马报](/features/ma-bao/)，用法是 `/report day` 或 `/report week`。

- `/report day`：太平洋时间的一天。
- `/report week`：太平洋时间周一到周日的一周。
- 两个子命令都有可选的 `when`：「进行中的今天 / 本周」（默认）或「上一个完整的一天 / 一周」。

回复是公开的，看马报不会改变自动发布的进度，也不会动身份组。

### /announcer

设置军师的声音和赛前语音。
两个选项至少要填一个。

- `style`：所有人都能改。
  选 Sweet Girl（甜美女声）或 Old Man（大叔声，默认），对整个服务器生效。
- `pregame_voice`：只有管理员能改。
  开或关 [军师赛前锦囊](/features/pregame/) 的语音，默认开，关掉后锦囊只发卡片。

回复只有你自己看得到。

## 管理员专用

这些命令需要服务器的管理员权限。

### /bind

把一位 Discord 成员和一个北美服 Riot 账号绑定。
绑定之后军师才会盯着这位成员。

| 选项 | 必填 | 说明 |
| --- | --- | --- |
| `user` | 是 | 要绑定的 Discord 成员 |
| `riotid` | 是 | Riot ID，格式 `召唤师名#标签` |

- 对同一位成员再用一次，就是给他加一个账号，或者刷新已有账号。
- 一个 Riot 账号已经属于另一位成员时会被拒绝，要先 `/unbind` 那位成员。
- 整个服务器最多 10 个 LoL 账号，所有成员加起来算。
- 每位成员按绑定的先后排序，战报里的顺序也按这个来。

### /unbind

| 选项 | 必填 | 说明 |
| --- | --- | --- |
| `user` | 是 | 要解除绑定的成员 |

移除这位成员的全部账号，军师不再盯着他。
其他成员不受影响，他的马厩记录会保留。

### /bindings

没有选项。
按绑定顺序列出这个服务器里所有被绑定的成员和他们的账号。

### /report-settings

设置 [马报](/features/ma-bao/) 的自动发布。
子命令：

- `/report-settings show`：看当前的频道、开关和身份组设置。
- `/report-settings channel`：设置自动发马报的文字频道，选项 `channel` 必填，会先检查机器人在那里的权限。
- `/report-settings channel-clear`：清除频道，停止自动发布，其他设置保留。
- `/report-settings daily`：开关日报，选项 `enabled` 必填。
- `/report-settings weekly`：开关周报，选项 `enabled` 必填。
- `/report-settings roles`：开关每周身份组，选项 `enabled` 必填。
  可以用 `top-role` 和 `none-role` 指定已有的身份组，不指定就自动创建「本周特等马」和「本周没有马」。

没设频道之前不会自动发布。
设好频道之后，日报和周报默认都是开的。

### /stable-erase

清除一位成员的全部 [马厩](/features/stable/) 记录，真实和模拟的都清。

| 选项 | 必填 | 说明 |
| --- | --- | --- |
| `user` | 是 | 要清除记录的成员 |
| `confirm` | 否 | 填 `true` 才真的删除，不填只统计有多少条 |

删除之后无法恢复。

## 仅用于测试

这两个命令只给开发和验收用，普通玩家用不到。
它们只能在配置了测试服务器的那个服务器里用，并且要求管理员在语音频道里。

### /testvoice

让军师在你所在的语音频道里念一小段测试语音，确认语音播放是通的。
没有选项。

### /simulate

用模拟对局跑一遍完整的播报流程，只能在机器人运行于模拟模式时使用，不会用到真实战绩。

| 选项 | 必填 | 说明 |
| --- | --- | --- |
| `outcome` | 是 | 「胜利」「失败」「开局（赛前锦囊）」「晋级（模拟）」或「掉段（模拟）」 |

「晋级（模拟）」和「掉段（模拟）」会先把第一个模拟账号放在升降段的边缘，再模拟一局胜利或失败，用来看 [段位变化和段位播报](/features/game-end/#段位变化) 的效果。

模拟出来的内容都会明确标注为模拟数据，详见 [隐私与公平](/privacy/)。
